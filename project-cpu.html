DWG-003 · Case study

8-Bit CPU From Logic Gates

Type  Personal project
Tools  Verilog, GTKWave
Year  2025
01 — OVERVIEW

Building a CPU from the transistor level up

This was a self-directed project to really understand computer architecture from the ground up, rather than just using the abstractions everyone takes for granted. I built a fully functional 8-bit CPU in Verilog, starting from primitive logic gates and working upward, one building block at a time, until those blocks combined into a working processor with its own instruction set.

02 — HOW IT WAS BUILT

From gates to a working processor

  • Primitive gates I started at the lowest level, writing AND, OR, NOT, XOR, and NAND gates directly in Verilog, then used them to build flip-flops — the basic memory element everything else in the design depends on.
  • Combinational and sequential building blocks From those gates and flip-flops, I built up larger structures: multiplexers, adders, registers, and counters — the same kind of reusable blocks a real CPU is built from.
  • Functional units Those building blocks came together into the CPU's major functional units: an ALU for arithmetic and logic operations, a register file, RAM and ROM for data and program storage, and a program counter to track execution.
  • Control unit and instruction set I designed a custom instruction set architecture and wrote the control unit that decodes instructions and drives every other block — the piece that turns all the individual components into a single working CPU.
  • Verification I wrote microcode programs and testbenches to simulate the design in GTKWave, checking that every instruction executed correctly and that timing held up across the whole datapath.

03 — WHAT IT DOES

A small but complete instruction set

The finished CPU supports load/store operations, arithmetic and logic instructions, branching, and jumps — enough to run real, if simple, programs. It's a small system, but every piece of it, down to the individual gates, was built and verified by hand rather than pulled from a library.
